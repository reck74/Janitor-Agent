# Repository Research Agent — Design Lines

This document defines the visual identity of the HTML report generated by the agent.

## Color Palette

| Role       | Hex       | Usage                              |
|------------|-----------|-------------------------------------|
| Primary    | `#2563eb` | Links, headers, active states       |
| Secondary  | `#1e293b` | Cards, sidebars, surfaces           |
| Accent     | `#10b981` | Success indicators, completados     |
| Warning    | `#f59e0b` | Warnings, cautions                  |
| Danger     | `#ef4444` | Critical issues, errors             |
| Background | `#0f172a` | Page background                     |
| Surface    | `#1e293b` | Card backgrounds                    |
| Text       | `#f1f5f9` | Primary text                        |
| Muted      | `#94a3b8` | Secondary text, labels               |
| Border     | `#334155` | Borders, dividers                   |

## Typography

- **Headings**: `Inter`, system-ui, sans-serif
- **Body**: `Inter`, system-ui, sans-serif
- **Code**: `JetBrains Mono`, `Fira Code`, monospace
- **Base size**: 14px
- **Line height**: 1.5

## Spatial System

- Base unit: 4px
- Spacing scale: 4, 8, 12, 16, 24, 32, 48, 64px
- Border radius: 6px (cards), 4px (buttons, code)
- Max content width: 1200px

## Layout Structure

```
+-----------------------------------------------------+
| HEADER: Project name + repo URL + badges             |
+-----------------------------------------------------+
| TABS: Resumen | Analisis | Evaluacion               |
+-----------------------------------------------------+
|                                                     |
|  CONTENT AREA                                       |
|  - Styled markdown sections                         |
|  - Code blocks with dark background                 |
|  - Tables with alternating row colors               |
|  - Callout boxes (warning/note/success)            |
|                                                     |
+-----------------------------------------------------+
| FOOTER: Generated by Janitor + timestamp            |
+-----------------------------------------------------+
```

## CSS Requirements

- All CSS must be inline in `<style>` tag
- No external CSS or JS dependencies
- Mobile responsive: single column below 768px
- Print-friendly: hide nav, expand content
- Syntax highlighting for code blocks

## Component Styles

### Cards
```css
.card {
  background: #1e293b;
  border: 1px solid #334155;
  border-radius: 6px;
  padding: 16px;
  margin-bottom: 16px;
}
```

### Badges
```css
.badge {
  display: inline-block;
  padding: 4px 8px;
  border-radius: 4px;
  font-size: 12px;
  font-weight: 500;
}
```

### Tables
```css
table {
  width: 100%;
  border-collapse: collapse;
}
th, td {
  padding: 8px 12px;
  border-bottom: 1px solid #334155;
}
tr:nth-child(even) {
  background: #1e293b;
}
```

## Animations

- Transitions: `150ms ease-out`
- Hover lift on cards: `translateY(-2px)`
- No gratuitous animations
