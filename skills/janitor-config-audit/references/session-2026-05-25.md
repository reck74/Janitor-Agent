# Config Audit — Hallazgos de la Sesion 2026-05-25

## Unica diferencia encontrada

El archivo activo `~/.janitor/config.yaml` carecia de la seccion `janitor.language_instruction`
que si existe en el asset master (`janitor-core/assets/janitor/config.yaml`).

**Solucion aplicada:** Se inserto manualmente el bloque via sed en la linea 10:

```yaml
janitor:
  language_instruction: "IMPORTANT: You must respond only in Spanish or English. ..."
```

## Mecanismo de comando slash

- `/janitor-config-audit` se registra automaticamente via `scan_skill_commands()`
- Nombre derivado del `name:` en el frontmatter (sin mayusculas, guiones en vez de espacios)
- Disponible tras `/reload-skills`
- Tambien invocable directamente via `/skill janitor-config-audit`

## Validacion

Despues de cualquier modificacion al config.yaml, siempre validar con:

```bash
python3 -c "import yaml; yaml.safe_load(open('/home/reck/.janitor/config.yaml')); print('YAML valido')"
```
