# Research Output Template

Use this template structure for each analysis section.

## Section Template

```markdown
# {Section Title}

## Overview
{Brief description of what was analyzed}

## Key Findings

### Finding 1
- **What**: {description}
- **Evidence**: {file path or link}
- **Impact**: {low/medium/high}

### Finding 2
...

## Metrics
| Metric | Value | Notes |
|--------|-------|-------|
| Metric 1 | Value | Notes |

## Recomendaciones

1. **{Action}**: {Why it matters}
2. **{Action}**: {Why it matters}
```

## Quick Reference

### Metadata Collection
- Stars, forks, watchers
- License
- Last commit date
- Contributor count
- Open issues/PRs ratio
- Primary language

### Architecture Analysis Checklist
- [ ] Directory structure mapped
- [ ] Entry points identified
- [ ] Key modules documented
- [ ] Data flow traced
- [ ] External dependencies listed

### Security Checklist
- [ ] Dependencies audited
- [ ] No hardcoded secrets
- [ ] Configuration reviewed
- [ ] Git history checked for secrets
- [ ] Dependencies versions checked

### Quality Checklist
- [ ] Test coverage estimated
- [ ] Code duplication found
- [ ] Tech debt identified
- [ ] Naming conventions checked
- [ ] Error handling reviewed
